## Two commands. Done.

```bash
# One-time install
dotnet tool install --global Nikcio.OpenApiCodeGen

# Any spec — local file or URL, JSON or YAML
openapi-codegen https://petstore3.swagger.io/api/v3/openapi.json -o Petstore.cs -n MyApp.Pets
```

## From YAML to `record` in one pass

<SpecToCode
  leftFile="petstore.yaml"
  rightFile="Petstore.cs"
  leftBadge="your spec"
  rightBadge="generated"
  leftLang="yaml"
  rightLang="csharp"
  leftCode={`openapi: 3.0.3
info:
  title: Petstore
  version: 1.0.0
components:
  schemas:
    Pet:
      type: object
      required: [name, photoUrls]
      properties:
        id:
          type: integer
          format: int64
        name:
          type: string
        photoUrls:
          type: array
          items:
            type: string
        status:
          type: string
          description: pet status in the store
          enum: [available, pending, sold]`}
  rightCode={`/// <summary>
/// pet status in the store
/// </summary>
[JsonConverter(typeof(JsonStringEnumConverter))]
public enum PetStatus
{
    [JsonStringEnumMemberName("available")]
    Available,
    [JsonStringEnumMemberName("pending")]
    Pending,
    [JsonStringEnumMemberName("sold")]
    Sold
}

public record Pet
{
    [JsonPropertyName("id")]
    public long? Id { get; init; }

    [JsonPropertyName("name")]
    public required string Name { get; init; }

    [JsonPropertyName("photoUrls")]
    public required IReadOnlyList<string> PhotoUrls { get; init; }

    /// <summary>
    /// pet status in the store
    /// </summary>
    [JsonPropertyName("status")]
    public PetStatus? Status { get; init; }
}`}
 />

Every mapping is deliberate: `int64` becomes `long`, `required` stays `required`, descriptions become XML doc comments, and enums keep their wire names.

## Opinions included

The README says _opinionated_. Here's what that means in practice:

- **Records over classes.** Value semantics, `with` expressions, `init`-only — because API models are data, not behavior.
- **Immutable over mutable.** Collections are read-only unless you say otherwise. If your code mutates a DTO, that deserves a second look.
- **Nullable over hopeful.** If the spec doesn't require it, it's `T?`. The compiler — not a `NullReferenceException` in production — tells you what can be missing.
- **String enums over magic numbers.** `PetStatus.Available`, not `(PetStatus)0`.
- **Models over megazords.** You get types, not a generated HTTP client you didn't ask for. Bring your own client, or none.
